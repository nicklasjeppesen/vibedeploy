Giv din AI adgang til din server

Kopiér adressen, og tilføj den som en ny forbindelse (MCP) i din AI. Så kan den bygge og udgive apps for dig.

{{.Data.MCPURL}}
  1. Åbn din AI, og find stedet, hvor man tilføjer en ny forbindelse (MCP).
  2. Indsæt adressen, og kald forbindelsen fx Min server.
  3. Du sendes hertil igen for at logge ind og godkende.
{{if .Data.Connected}}Forbundet. Du kan nu bede din AI om at udgive en app.{{else}}Venter på, at din AI forbinder …{{end}}
{{if .Data.Local}}
Du kører lokalt. Claude Code og andre værktøjer på denne maskine kan bruge adressen direkte. Webtjenester som claude.ai kræver en offentlig https-adresse; start serveren med -public-url bag en tunnel (se README).
{{end}}

Claude Code (kommandolinje)

claude mcp add --transport http min-server {{.Data.MCPURL}}

Kør derefter /mcp i Claude Code, og vælg «Authenticate».
